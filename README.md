# Personal Portfolio & Showreel

Thuy An Ngo?s portfolio featuring motion design, production, graphic art, UI/UX, and sound.

## Preview

Serve this folder with a local static web server and open `index.html`. No build step is required. Keep the `assets/` folder beside the HTML, JavaScript, and CSS files.

## Contents

- `index.html`: entry page and project catalogue
- `screen-blog.js` / `screen-blog.css`: playlist and project layouts
- `project-content.js`: project copy and credits
- `assets/`: images, fonts, and media
